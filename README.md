# Propuesta — Mario Gabriel Pizzorno

Mini web de presentación personal para la postulación de Mario como vendedor digital de un local de indumentaria.

Es un sitio estático: `index.html` + las carpetas `img/` y `video/`. No necesita build ni backend.

## Editar contenido

Todo lo reemplazable (fotos de la galería, celulares de "Mi emprendimiento", reels, ejemplos de Mostrar / Conectar / Vender y el link de Instagram) está en el objeto `CONFIG`, al principio de `index.html`.

## Publicar con GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, carpeta `/ (root)`.
